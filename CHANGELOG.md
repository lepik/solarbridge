# Changelog

Все заметные изменения SolarBridge документируются в этом файле.
Формат — Keep a Changelog; версии — semver.

## [1.0.1] — 2026-11-15

### Изменено (редизайн интерфейса, функциональных изменений нет)

- **Светлая тема по умолчанию** («тёплый белый + синий»); тёмная — «графит +
  энерго-зелёный». Обе палитры на CSS-переменных, canvas-график красится из темы.
- **Компактная шапка-тулбар** вместо hero-блока: бренд, чип устройства,
  последние данные, алармы, статус, язык/тема/обновление — всегда под рукой.
- **Таб-полоса 01–09** под шапкой: якорная навигация по секциям (нумерация
  сохранена). Секции получают `id` для якорей.
- Карточки «01 / СЕЙЧАС» уплотнены до ленты KPI-плиток; орбит-флоу и заголовок
  «Энергия под контролем.» удалены; панели — плоские (радиус 10–14, без
  градиентов); типографика — системные шрифты (Segoe UI Variable / Cascadia).
- Переписаны все наследуемые тексты интерфейса (ru/en): подписи карточек,
  статусные сообщения, футер, заголовки секций.
- Мобильная версия: лента 2→1 колонки, шапка без второстепенных чипов,
  таб-полоса с горизонтальной прокруткой.
- Отчёт `/report`: печатная палитра приведена к новой идентичности.
- 149 юнит-тестов.

## [1.0.0] — 2026-11-14

Первый релиз с деньгами: тарифы ₽/кВт·ч, финансовые дашборды, метрики машины
мастера, печатный отчёт и самостоятельное обновление из публичного репозитория.

### Добавлено

- **Восстановление мастера из базы приёмника** (умерла SD-карта): копия базы
  приёмника импортируется в БД мастера с дедупликацией по
  `(master_id, captured_ts)`; режимы «всё», «диапазон дат», «с даты до
  конца». Пункт меню install.py «Восстановить данные из базы приёмника»;
  процедура задокументирована (README/INSTALL).
- **master_id со случайным суффиксом**: визард генерирует
  `hostname-XXXXXXXX` (например `raspberrypi-B349HCFD`) и записывает в `.env`
  один раз — защита от «подставного» мастера при сохранении дедупликации.
- **Вход по логину/паролю** (опция `SB_AUTH=1`): пары в файле `user_list`
  рядом с `.env` (формат `login:password`, открытый текст); после входа
  браузер хранит токен 30 дней (cookie + localStorage) и повторно пароль не
  спрашивает. Закрываются все данные дашборда (`/api/*`, SSE); ингест и seed
  остаются на собственных Bearer-токенах. Создание user_list — вопрос
  визарда install.py.
- **Дисковый сторож** `SB_DISK_MIN_FREE_PERCENT` (по умолчанию 10%): при
  достижении порога мастер прекращает писать кадры в свою БД и передаёт их
  приёмникам напрямую (live-канал форвардера), даш показывает красное
  предупреждение; `0` — выключено.
- **Обслуживание базы** (install.py): «удалить данные до даты» — удаление
  сэмплов и батарейных строк старше даты с VACUUM.
- **Тарифы и финансы.** Секция «08 / ФИНАНСЫ»: карточки «Вчера» (итог) и
  «Сегодня · LIVE» — PV-генерация, экономия PV, нагрузка, покупки из сети и
  расходы, заряд батареи (в т.ч. из сети), разряд, PV в сеть дома и итог
  (экономия − расходы). Панель «ТАРИФ» компактна: видна текущая ставка и
  дата, редактор и история раскрываются по «Подробнее». История тарифов
  хранится в БД (`tariffs`), активный помечен. Правка тарифа мгновенно
  пересчитывает историю — **стоимости в БД не хранятся**, деньги считаются
  на момент показа по тарифу соответствующей даты (тариф применяется к
  покупкам из сети; экономия PV = вся генерация × тариф; разряд батареи —
  в kWh без двойного учёта). Одна ставка (день/ночь — задел на будущее),
  настройка локальная на каждой машине.
- **«09 / PC MASTER POLL» («PC Master»)** — метрики хоста мастера:
  температура CPU, load 1/5/15, RAM, диск, uptime сервиса и машины, флаг
  throttling Raspberry Pi (`vcgencmd`), возраст heartbeat. Передаётся в
  `/api/current` и в heartbeat приёмникам (подмножество). Отключается
  `SB_HOST_STATS=0`.
- **Баннер расхождения версий** на приёмнике: мастер и приёмник показывают
  предупреждение, если версии SolarBridge не совпадают; смена версии мастера
  пишется в события (`master_version`).
- **Печатный отчёт `/report`**: `?days=7|30|90|365` или произвольный диапазон
  `?from=ГГГГ-ММ-ДД&to=ГГГГ-ММ-ДД`. Сводка KPI периода, SVG-график
  PV/нагрузка/сеть по дням или месяцам, таблица суток/месяцев с итогами,
  рекорды периода, снимок батарей, события мастера. Кнопка «Отчёт PDF» на
  дашборде; PDF — через печать браузера (Ctrl+P, print-CSS, A4).
- **`update.py`** — обновление из публичного релиза: release = zip + .sha256,
  источник — `SB_UPDATE_URL` в `.env` (репозиторий GitHub или прямой URL zip).
  Режимы `--check` (только сравнить версии) и `--from FILE.zip` (офлайн),
  `--force` разрешает даунгрейд. Перед применением — бэкап; если служба не
  поднялась по `/healthz` за 60 с — автоматический откат. `.env`, `data/`,
  `receivers.list` и `.venv` никогда не перезаписываются. Скрипт входит в
  состав пакета и миграционного архива.
- **Расшифровка регистра 20142 «System setting»** (display-only): биты 0–6
  (запрет рестарта при перегрузке/перегреве, запрет bypass, автолистание LCD,
  зумер, подсветка) показываются в «06 / CONFIG» рядом с сырым кодом.
- Роуты `GET/POST /api/tariffs`, `DELETE /api/tariffs/{id}`,
  `GET /api/finance?days=&tz=&to=`, страница `/report`,
  `POST /api/auth/login`, `GET /api/auth/status`.

### Изменено

- **Финансы v2 — по счётчикам инвертора.** `finance()` считает дневные kWh всех
  потоков дельтами аппаратных счётчиков (0.1 кВт·ч: load/buy/sell/charger/
  discharger/grid_charger из блока 25245–25260, PV из 15217–18) между локальными
  полуночами — точно, независимо от частоты опроса, пики учитываются железом.
  Дни без пригодных счётщиков считаются интеграцией (`source: integration`).
  Отрицательная дельта (сброс счётчиков регистром 20213) → откат дня на
  интеграцию. Опрос (15 с) и кадр (60 с) не тронуты, БД не растёт.
- **Исправлена конвенция знака сети** (проверено на живом железе): у HIDEN
  `grid_power_w < 0` = покупка. Интеграция финансов и тайлы «сегодня» считали
  наоборот — покупки уходили в «продажу», тайл «Сеть» показывал 0,00 при
  реальном потреблении. Тайлы «сегодня» теперь берут числа из `/api/finance`
  (счётчики), fallback-интеграция исправлена.
- Карточки «Вчера»/«Сегодня»: новый итоговый блок **«Итого в нагрузку»**
  (кВт·ч в дом) и **«Стоимость по тарифу»** (вся нагрузка, оценённая тарифом;
  фактические затраты — строка «Расходы»).
- Мутации тарифов защищены same-origin проверкой (наряду с ingest-токеном).
- Аудит регистров протокола: все 7 блоков xlsx опрашиваются и декодируются,
  54 кода неисправностей совпадают с листами протокола бит-в-бит.
- Исправлен латентный баг хранения батарейных кадров на мастере
  (неопределённая переменная в пути insert_battery_frame глоталась except'ом).
- Исправлены два падения HTTP на мастере: `/api/current` и SSE `/api/events`
  (HostStats передавался как объект вместо метода `snapshot`; в SSE-рукопожатии
  остался вызов переименованного хелпера). Добавлены регрессионные тесты.
- 140 юнит-тестов (было 129): авторизация, дисковый сторож, восстановление
  из базы приёмника, live-кадры форвардера, флаги 20142.

## [0.9.0] — базовый релиз (архив `RC_V_0.9.0`)

- Архитектура «мастер → приёмник»: heartbeat 15 с, догрузка пропусков
  батчами, окно догрузки, пересев (seed) по одноразовым ссылкам,
  `schema_version` в кадрах.
- Мониторинг батарей Pylontech по отдельному RS485-адаптеру (модули, ячейки,
  SOC/SOH, защита/тревоги).
- Полный дашборд: живые обновления по SSE, история с бакетами
  минута/30 мин/час/день, CSV-экспорт, диагностика с сырыми регистрами,
  русский и английский интерфейс, тёмная и светлая темы.
- Строгий read-only: в коде нет ни одной команды записи в инвертор/BMS.
